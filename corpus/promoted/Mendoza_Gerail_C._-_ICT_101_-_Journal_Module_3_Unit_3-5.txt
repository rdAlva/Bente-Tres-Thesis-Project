1. System memory, commonly referred to as primary memory, is the short-term data storage used 
by a computer's CPU. Because it is volatile, all information in system memory is lost when the 
machine shuts down. Although system memory is incredibly quick, it is also relatively expensive 
and has a little amount of space.  
 
Data that is not actively being used by the CPU is permanently stored in mass storage, 
commonly referred to as secondary storage. Data is kept even when the computer is shut off since 
it is non-volatile. While mass storage is more expensive and has a bigger capacity, it is slower than 
system memory. 
 
2. System memory most often used is random-access memory (RAM). It is volatile, which means 
that when the computer is powered down, the data in RAM is lost. Because RAM is so speedy, the 
CPU can access data with ease and speed. The operating system, applications, and data that the 
computer is now using are kept in RAM.  
 
Read-only memory (ROM): Since ROM is non-volatile, the data stored inside is kept even 
when the computer is powered down. Important system files like the BIOS and firmware are kept 
in ROM. Additionally, information that must always be available is stored in ROM, such as the 
BIOS's language preferences. In addition, unlike ROM memory, which cannot be overwritten, 
RAM memory allows for unrestricted, limitless value changes. 
 
3.  An SSD is the ideal option if you want the fastest and most reliable storage device. But the price 
of SSDs is also higher than that of HDDs. An HDD is a more cost-effective choice if you require 
a lot of storage space but are on a tight budget. The computer may use a portion of the hard drive 
for storage if there is not enough space to store all of the programs and data files that are needed. 
If the disk is slow, performance will suffer when the computer tries to load programs and data files
