Batch files - Batch files are a straightforward programming language used to automate processes. 
They are composed of a string of orders that are carried out one after the other. Frequently, 
repetitive actions like backing up files or altering system settings are carried out using batch files. 
Windows PowerShell - Based on.NET, Windows PowerShell is a more robust scripting language. 
It offers a large variety of cmdlets (commands) that can be used to manage resources, automate 
operations, and communicate with Windows. System administrators frequently use Windows 
PowerShell to carry out difficult administrative tasks. 
Visual Basic Scripting Edition (VBScript) - A scripting language based on Visual Basic is called 
VBScript. Despite having less power than Windows PowerShell, it can still be useful for 
automating processes. Developers frequently use VBScript to produce scripts that communicate 
with Windows programs.
